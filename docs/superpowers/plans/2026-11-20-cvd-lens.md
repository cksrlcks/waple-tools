# 색맹 안경 (`a11y.cvd_lens`) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 접근성 탭에 추가 설치 도구 "색맹 안경"을 만든다 — 보기 방식 버튼 4개 중 하나를 누르면 아래 화면을 색각이상 시뮬레이션으로 비추는 떠 있는 렌즈 창이 뜬다.

**Architecture:** 새 크레이트 `crates/tools/a11y-cvd-lens`(Interactive, `x-input: "none"`)가 `run()`에서 Win32 렌즈 스레드를 띄우거나(없으면) 기존 렌즈에 보기 방식을 보내고 바로 돌아온다. 렌즈는 Magnification API(배율 1, `MagSetColorEffect`)로 그린다. 앱에는 공용 부품 하나: enum 필드의 `x-run-buttons: true`를 값마다 버튼으로 그리고 누를 때만 실행하는 작업대.

**Tech Stack:** Rust(`windows-sys 0.61.2`, schemars, serde), React + TanStack Query + vitest

**Spec:** [docs/superpowers/specs/2026-11-20-cvd-lens-design.md](../specs/2026-11-20-cvd-lens-design.md)

## Global Constraints

- 브랜치: `main`에서 `git switch -c feat/cvd-lens` (worktree 금지).
- 새 의존성은 `windows-sys = "0.61.2"` 하나뿐(MIT/Apache-2.0, 잠금 파일에 이미 있음). 커밋 메시지에 이유·라이선스.
- 네트워크·Tauri 권한·외부 리소스 추가 금지. 원본 파일·`out_dir`에 쓰지 않는다.
- 화면 문구·오류 메시지는 한국어. 화면 코드(`app/src`)에 `#hex`·`bg-[…]`·`text-gray-500` 같은 토큰 밖 색 금지 (Win32 렌즈의 색 상수는 화면 코드가 아님).
- 상단 X 아이콘 금지 — 렌즈 손잡이의 닫기는 글자 [닫기].
- 색 행렬은 감마 공간 근사 → 코드에 `ponytail:` 주석.
- 매 작업 끝: `cargo fmt --check`, `cargo clippy --workspace -- -D warnings`, `cargo test --workspace`, 프론트 변경 시 `cd app && npx tsc --noEmit && npm test`.
